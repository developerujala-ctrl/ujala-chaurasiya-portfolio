Ujala Chauraiya — Developer Portfolio

A responsive React portfolio powered by Vite. The original portfolio content,
links, visual design, responsive stylesheet, theme toggle, and reveal effects
are retained.

Requirements
------------
- Node.js 20.19+ or 22.12+
- npm

Run locally
-----------
1. Run `npm install`.
2. Run `npm run dev`.
3. Open the local URL printed by Vite.

Build and preview
-----------------
- Run `npm run build` to generate the production-ready site in `dist/`.
- Run `npm run preview` to preview the production build locally.

Customize
---------
- Edit portfolio sections and content in `src/App.jsx`.
- Adjust colors and responsive styles in `style.css` (start with `:root`).
- Update package scripts and dependencies in `package.json`.
- Google Fonts are loaded online; system fonts are used if they are unavailable.
- The email links open the visitor's email application; there is no backend
  contact form.

Before publishing, add real repository links and any resume or project details
you want to share.
